# my-skills-compilation

My global Claude Code skills, plus my global rules.

- `global-rules/CLAUDE.md` — my global instructions for all projects.
- Every other folder is one skill (`SKILL.md` + its references).

## Install

Clone into your Claude Code skills directory:

```bash
git clone https://github.com/jhonivancuaco/my-skills-compilation.git ~/.claude/skills
```

To use the global rules, copy them into place:

```bash
cp ~/.claude/skills/global-rules/CLAUDE.md ~/.claude/CLAUDE.md
```
